// how it works

The agentic loop.

01 — name_outcome()

Name the outcome

Type your goal in natural language. NIM parses intent, decomposes it into sub-goals, and selects the optimal tools for web navigation, form handling, or data extraction.

02 — read_page()

Inspect the DOM

The engine extracts clean, semantic interactive elements, assigning numerical index tags to interactive inputs, buttons, and links without noisy markup.

03 — actuate_web()

Actuate and verify

Executes clicks, multi-field form fills, and scrolls with verification. Any high-risk financial or irreversible actions prompt Human-In-The-Loop approval.

04 — synthesize()

Synthesize and conclude

Formats findings into structured markdown notes, exports files to your Downloads folder, or triggers background watch monitors for ongoing tracking.

Privacy-first. Controllable.

Your data stays yours

API keys and session notes are saved strictly in Chrome extension local storage. No analytics or server logging.

02 — Form Shield

// ready to deploy

Run NIM AGENT in your browser.

Open source under PolyForm Noncommercial 1.0.0. Clone, build with npm, and load unpacked into Chrome, Edge, Brave, or Firefox.

Clone Repository @mahamadali210
Chrome · Edge · Brave · Opera · Firefox (Manifest V3)
Build Extension From Source
  1. 01 git clone https://github.com/mohammedila812-NIM/NIM_AGENT.git && cd NIM_AGENT
  2. 02 npm install && npm run build
  3. 03 Open chrome://extensions → Enable Developer Mode
  4. 04 Click Load unpacked → Select .output/chrome-mv3
Quick Launch & Shortcut
  1. 01Pin the NIM Agent icon to your browser toolbar
  2. 02Click the Settings gear and enter your NVIDIA NIM or Gemini API key
  3. 03Press Alt+Shift+N on any page to open the Side Panel
