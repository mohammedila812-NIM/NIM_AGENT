What It Does

A Real AI Agent, In Your Browser

Not just a chatbot. NIM Agent navigates, clicks, types, scrolls, and reasons across real web pages — entirely locally.

🔁

ReAct Loop Engine

Full Reason → Act → Observe loop with tool calling, intent classification, and adaptive context compression for long tasks.

🌐

Multi-Tab Parallel Research

Spawn up to 5 independent sub-agents across separate background tabs, each clicking and scrolling its own page simultaneously.

🛡️

Human-in-the-Loop Safety

Destructive actions (delete, checkout, submit) always pause and require your explicit click-to-approve before executing.

📝

Batch Form Auto-Fill

Fill out entire multi-field registration, checkout, or filter forms in a single atomic turn with framework-aware event dispatching.

🔍

Prompt Injection Protection

Built-in quarantine layer runs extracted web content through a sandboxed LLM to detect and block prompt injection attacks.

🧠

On-Demand Session Recall

Intelligently queries previous research steps and past tasks across turns without bloating token costs or context limits.

How It Works

Simple to Set Up

No servers, no cloud login, no subscriptions. Just your browser and an API key.

1

Download & Install

Download the ZIP, extract it, then load it as an unpacked Developer Extension in Chrome.

2

Add Your API Key

Open Settings in the sidepanel, paste your NVIDIA NIM, Groq, Gemini, Ollama, or OpenRouter API key.

3

Pick a Model

Click "Fetch Models" to auto-discover available models, then select one with tool-calling support.

4

Start a Task

Open the NIM Agent sidepanel on any page, type a task description, and watch the agent go to work.

No Web Store Required

Load as
Developer Extension

NIM Agent is not published to the Chrome Web Store. To use it, you load it manually as an unpacked extension — a standard Developer Mode feature built into Chrome.

1

Download the ZIP

Click the Download button below to get the latest release ZIP file of the extension.

2

Enable Developer Mode

Open chrome://extensions, toggle "Developer mode" on in the top right corner.

3

Load Unpacked

Click "Load unpacked", navigate to the extracted ZIP folder, and select the .output/chrome-mv3 directory.

4

Pin to Toolbar & Open

Pin the NIM Agent icon to your toolbar, click it to open the sidepanel, and configure your API key in Settings.

📦 Or Build From Source

If you want to modify or contribute, build the extension yourself:

# Clone the repository
git clone https://github.com/mohammedila812-NIM/NIM_AGENT.git
cd NIM_AGENT

# Install dependencies
npm install

# Build the extension
npx wxt build

# Output in .output/chrome-mv3/

✅ System Requirements

  • • Chrome 120+ or any Chromium-based browser
  • • Node.js 18+ (for building from source)
  • • An API key from any OpenAI-compatible provider
